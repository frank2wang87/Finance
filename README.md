# 投资手记 Finance

Python + HTML/CSS/原生 JavaScript 的个人投资账本。SQLite 本地保存数据，无需账户、数据库服务或前端构建。

## 启动

需要 Python 3.10+。在仓库根目录运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

浏览器访问 `http://127.0.0.1:8000`。默认仅监听本机，`HOST`、`PORT` 可配置。它是个人单用户工具，未实现登录或多用户隔离；公网部署需要额外认证与 HTTPS。

## 使用

1. 初始化总本金和起始日期，资金自动进入余额宝账户。
2. 添加纳斯达克、标普500、沪深300等自定义标的。
3. 记录买入/卖出的日期、金额、成交净值、手续费及投资理由。成交金额不含手续费，份额自动计算。
4. 定期录入“更新估值”，将持仓按指定净值重估。
5. 按全部资产或单个标的查看每日市值/累计收益曲线，筛选流水，导出 CSV 或 Excel。Excel 包含流水、每日资产及持仓汇总三个工作表。

## 计算约定

- 初始本金一次性投入，当前版本不支持后续出入金、分红、拆分、融资、做空或多币种。
- 买入从现金扣除成交金额及手续费；卖出将成交金额减手续费计入现金。
- 剩余成本包含买入手续费，卖出按移动加权平均成本结转；已实现收益为卖出净收入减结转成本。
- 标的累计收益 = 最新市值 − 剩余成本 + 已实现收益；标的收益率的分母为历史累计买入金额及买入手续费，不是年化或资金加权收益率。
- 总资产 = 现金 + 所有标的市值；总收益 = 总资产 − 初始本金。总收益率以初始本金为分母。
- 余额宝使用固定有效年化 1%，按 `(1.01 ** (1/365) - 1)` 对每日期初现金计息；起始日不计息。仅用于估算，不代表真实产品收益。
- 总资产年化收益率 = `(总资产 / 初始本金) ** (365 / 经过天数) - 1`，零天或总资产为零时不显示。最大回撤按每日收盘总资产计算，初始本金纳入峰值。
- 采用手动价格，不自动连接行情接口。没有估值的日期沿用上一净值，曲线不能代表未录入的真实市场波动。同日记录按录入顺序处理；流水中的总收益为该条记录处理完成时的快照。
- 历史新增/删除将重算全部账本；若使后续交易出现现金不足或超卖，则整次操作回滚。本金初始化后不直接修改，以免改变历史口径。
- 金额内部使用双精度浮点数，界面显示两位小数，属于个人分析工具，不用于会计结算。

## 数据与测试

默认数据文件为 `data/finance.db`（Git 忽略）。停止服务后备份此文件；`FINANCE_DB` 可指定独立数据库路径。启动不会插入演示流水或覆盖现有数据。

```bash
.venv/bin/python -m unittest discover -s tests -v
```

CSV 使用 UTF-8 BOM 方便 Excel 打开，CSV/Excel 文本单元格防止公式注入。Excel 导出需要 requirements.txt 中的 openpyxl。
